# Documentation

Read one file for the task at hand:

- [configuration.md](configuration.md): read it to set the env vars, share a
  storage root between instances, turn on CI, or recover the admin token.
- [deploy-scaleway.md](deploy-scaleway.md): read it to deploy gitmote on Scaleway,
  change the deploy pipeline, or debug a cloud instance.
- [architecture/](architecture/README.md): read it before you change how gitmote
  stores data, serves git, authenticates or runs CI.
- [evolution/](evolution/): read it to see directions the design may take. These
  files are ideas, not plans.
- [notes/](notes/README.md): read it before you settle an open design question.

To build, test or change gitmote, start with [CONTRIBUTING.md](../CONTRIBUTING.md).
