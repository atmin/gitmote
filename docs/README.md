# Documentation

Read one file for the current task:

- [configuration.md](configuration.md): read it to set the env vars or turn on
  CI. Read it also to share a storage root, or to recover the admin token.
- [deploy-scaleway.md](deploy-scaleway.md): read it to deploy gitmote on Scaleway.
  Read it also to change the deploy pipeline, or to debug a cloud instance.
- [architecture/](architecture/README.md): read it before you change how gitmote
  stores data or serves git. Read it also before you change auth or CI.

To build, test or change gitmote, start with [CONTRIBUTING.md](../CONTRIBUTING.md).
